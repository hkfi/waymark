# Feature Handoff Workflow

Use this workflow when turning a Waymark ticket into an AI implementation thread.

1. Read `AGENTS.md`, `ARCHITECTURE.md`, and the relevant docs.
2. Read `projects/waymark/tickets.yaml` and identify the ticket.
3. Check whether the ticket has a summary and acceptance criteria.
4. Read linked decisions, ideas, files, and thread summaries.
5. Generate or refine a scoped handoff prompt.
6. After implementation, update the ticket, add a thread summary, and create a decision record if a meaningful technical choice was made.

The handoff should be specific enough that another agent can implement without rediscovering project intent.
