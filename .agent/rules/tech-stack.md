# Technology Stack

- Desktop shell: Tauri 2.
- Frontend: React 19 + TypeScript + Vite.
- Native commands: Rust.
- Icons: `lucide-react`.
- Data parsing: `js-yaml`.
- Validation: `zod`.
- Package manager: pnpm.

## Constraints

- Markdown/YAML are canonical project storage.
- No backend is required.
- No SQLite in the MVP.
- No AI API calls in the MVP.
- Keep Tauri commands focused on local filesystem operations.
