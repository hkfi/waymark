# Agent-readable standards

Waymark should eventually be able to include relevant project standards in generated handoffs automatically. Examples include file-native data rules, UI density rules, Tauri filesystem rules, and testing expectations.

The first version can keep these standards in `AGENTS.md`, `.agent/rules/`, and `docs/`, then later expose them through the handoff context picker.
